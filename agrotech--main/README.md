# AgroTech

Projeto AgroTech com frontend estático e API Gemini hospedada na Vercel.

## Variável de ambiente

Na Vercel, crie:

`GEMINI_API_KEY` = sua chave da Gemini API

Não coloque a chave no frontend nem no GitHub.

## Estrutura

- `index.html` — página principal
- `script.js` — frontend
- `style.css` — estilos
- `api/chat.js` — endpoint da Gemini

## Deploy

Importe o repositório na Vercel e configure `GEMINI_API_KEY` em Environment Variables.
